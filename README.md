# Hi, I'm Arda 👋

I build practical tools for the Apple ecosystem, offline file conversion, and self-hosted personal cloud systems.

My projects focus on keeping files on your own devices, solving everyday problems, and documenting what works.

## Featured projects

### 🔄 [Convert](https://github.com/ardacob/convert-offline)
An offline file converter for **macOS and iPhone**, built with **Swift and SwiftUI**.

- Converts files on-device without uploading them to a server.
- Supports image/PDF conversion and selected audio/video conversions through system frameworks.
- Includes batch image conversion on iPhone, including **HEIC → JPG**, with gallery/file selection and sharing.
- Offers light, dark, and Liquid Glass themes.

Currently available as trial versions. Format support depends on the source file and the operating system's codecs.

[Explore the source](https://github.com/ardacob/convert-offline) · [Releases](https://github.com/ardacob/convert-offline/releases)

### ☁️ [Mac mini Personal Cloud](https://github.com/ardacob/mac-mini-personal-cloud)
A personal cloud and media storage setup using **Mac mini, external NVMe storage, Docker, File Browser, Tailscale, and NAStool**.

- Remote file access from iPhone/iPad through Tailscale.
- Shared storage for file management and media.
- Practical guides for APFS storage, HEIC previews, backups, and troubleshooting.
- Helper scripts and notes from a real Apple Silicon setup.

[Explore the setup](https://github.com/ardacob/mac-mini-personal-cloud) · [English guide](https://github.com/ardacob/mac-mini-personal-cloud/blob/main/README_EN.md)
